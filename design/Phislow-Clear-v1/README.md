# Phislow Clear 音符素材

仅提供设计素材，未修改、接入或构建 Android 应用代码。

按键保留已确认的青蓝 Click、金黄 Drag、玫红 Flick、薄荷青 Hold 样式。四种双押均有实心金色外环及白色内描边，保留原色键体。所有普通及双押 PNG 使用 1024 像素宽画布，填色键体在中心横截面统一对齐至 x=176..848，中心 x=512；高亮边框使用预留的透明空间，不压缩填色键体。

`skin/` 可直接打包为资源 ZIP，根目录包含 9 张透明 PNG 和 `info.yml`；音效省略。文件名与 Phiround.zip 一致，尺寸按本套统一宽度重新导出，不能混用参考包旧的切片参数。

| 类型 | 普通 / 双押 PNG 尺寸 |
| --- | --- |
| Click | 1024 × 192 |
| Drag | 1024 × 192 |
| Flick | 1024 × 256 |
| Hold | 1024 × 2048 |
| Hit effect | 2598 × 3464 |

长按普通及双押均自上至下切为尾部 160、身体 1728、头部 160 像素；身体单独拉伸。使用随包 `holdAtlas: [160, 160]` 与 `holdAtlasMH: [160, 160]`。

打击特效用 SVG 绘制，方框、菱形和两段旋转圆弧组成，中心闪光缩小后消失，末段透明淡出。`fx-svg/hit_fx.svg` 是完整矢量帧图，`frame-00.svg` 至 `frame-47.svg` 为每帧源文件；没有复制参考包的特效位图。每帧 433 × 433，6 列 × 8 行，从左上逐行播放，共 0.54 秒。白色透明特效可随判定染色。

`preview.png` 是普通/双押及小尺寸对照；`fx-preview.gif` 是带深色背景的循环预览。预览背景不包含在资源 PNG 中。

按键使用内置 imagegen 绘制，导出时统一尺寸及锚点；打击特效为 SVG 图形。绘制说明见 `prompts.json`，对齐记录见 `layout.json`。参考文件仅用于视觉方向与资源格式，未复制其音效。

资源格式依据：[Phira 官方资源包规范](https://teamflos.github.io/phira-docs/en/respack/index.html)。当前交付只验证素材格式、透明度、宽度和帧排列，未宣称已经在施工中的应用内完成接入测试。
